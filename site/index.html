Docker (local machine)

Runs on macOS, Windows or Linux. You need Docker Desktop or Docker Engine 20.10+ with Compose v2.

Option A: the installer

It downloads the compose file, writes a .env with random secrets and starts the stack.

curl -sSLO https://raw.githubusercontent.com/faisalahammad/tiergate/main/docker/install.sh
bash install.sh

Add --dry-run to see what it will do first, --dir /path to change the folder, or --port 8080 to change the port.

Option B: by hand

mkdir -p ~/tiergate && cd ~/tiergate
curl -sSLf https://raw.githubusercontent.com/faisalahammad/tiergate/main/docker/docker-compose.yml -o docker-compose.yml
printf 'BETTER_AUTH_SECRET=%s\nMANIFEST_ENCRYPTION_KEY=%s\n' "$(openssl rand -hex 32)" "$(openssl rand -hex 32)" > .env
docker compose up -d

Wait until docker compose ps shows both containers healthy (first boot takes up to 90 seconds), then open http://localhost:2099. The first account you create is the admin.

Keep a copy of .env. MANIFEST_ENCRYPTION_KEY encrypts your stored provider keys. If you lose it, they can not be decrypted.

VPS (Ubuntu, Debian, Oracle Cloud...)

1 vCPU and 1 GB RAM is enough. amd64 and arm64 (Ampere) images are both published.

  1. Install Docker: 
    curl -fsSL https://get.docker.com | sudo sh
sudo usermod -aG docker $USER   # log out and back in after this
  2. Install TierGate with the installer from the Docker step. The dashboard listens on 127.0.0.1:2099 only, so nothing is public yet.
  3. Point a DNS A record, for example ai.example.com, at the server IP.
  4. Open ports 80 and 443. With ufw: 
    sudo ufw allow 80,443/tcp
    On Oracle Cloud, also add ingress rules for TCP 80 and 443 in the VCN Security List, then: 
    sudo iptables -I INPUT 6 -m state --state NEW -p tcp --dport 80 -j ACCEPT
sudo iptables -I INPUT 6 -m state --state NEW -p tcp --dport 443 -j ACCEPT
sudo netfilter-persistent save
  5. Install Caddy for automatic HTTPS and put this in /etc/caddy/Caddyfile: 
    ai.example.com {
    reverse_proxy 127.0.0.1:2099
}
    sudo apt install -y caddy
sudo systemctl reload caddy
  6. Add BETTER_AUTH_URL=https://ai.example.com to the install's .env and run docker compose up -d.

To reach the dashboard before you have a domain, use an SSH tunnel and open http://localhost:2099:

ssh -L 2099:127.0.0.1:2099 user@your-server-ip

Dokploy

Dokploy runs the stack as a Docker Compose service and its Traefik proxy handles the domain and HTTPS.

  1. In your project, click Create Service and choose Compose. Name it tiergate.
  2. In General, choose the Raw provider and paste deploy/dokploy/docker-compose.yml. Save.
  3. In Environment, add these values. Generate each secret with openssl rand -hex 32: 
    BETTER_AUTH_SECRET=<random hex>
MANIFEST_ENCRYPTION_KEY=<random hex>
POSTGRES_PASSWORD=<random hex>
BETTER_AUTH_URL=https://ai.example.com
  4. In Domains, add ai.example.com with service tiergate, container port 2099, HTTPS on and the Let's Encrypt certificate.
  5. Click Deploy. When the logs show the app is listening, open your domain and create the admin account.
Do not change POSTGRES_PASSWORD after the first deploy. Postgres only reads it when the volume is created.

Coolify

Coolify generates the URL, database password and secrets for you with its magic variables.

  1. In your project, click New Resource and choose Docker Compose Empty.
  2. Paste deploy/coolify/docker-compose.yml and save.
  3. Check that Coolify filled in SERVICE_URL_MANIFEST_2099, SERVICE_PASSWORD_POSTGRES, SERVICE_HEX_64_AUTH and SERVICE_HEX_64_ENCRYPTION. Set your own domain on the manifest service if you want.
  4. Click Deploy, open the generated URL and create the admin account.

Check it is up:

curl -sSf https://your-coolify-domain/api/v1/health

Connect an agent

  1. In the dashboard, open Providers and connect at least one: an API key, a subscription, or a local server like Ollama.
  2. Open Harnesses, create one for your agent and copy its key (it starts with mnfst_).
  3. Point your agent at TierGate as an OpenAI-compatible provider:
SettingValue
Base URLhttps://ai.example.com/v1 (or http://localhost:2099/v1)
API keythe mnfst_... key
Modelauto
curl https://ai.example.com/v1/chat/completions \
  -H "Authorization: Bearer mnfst_YOUR_KEY" -H "Content-Type: application/json" \
  -d '{"model":"auto","messages":[{"role":"user","content":"Say hi"}]}'

Then open the harness, go to Routing and turn on Route by complexity to pick models for the Simple, Standard, Complex and Reasoning tiers.

Upgrade

Back up the database first. Migrations run by themselves when the new version starts.

docker compose exec -T postgres pg_dump -U manifest manifest | gzip > tiergate-$(date +%F).sql.gz
docker compose pull && docker compose up -d

On Dokploy or Coolify, click Redeploy. Coming from Manifest? Run the installer with --upgrade --dir "$PWD" in your existing install folder. Your .env and data are kept. See the migration steps.
